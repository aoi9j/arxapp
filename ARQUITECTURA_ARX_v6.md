# ARX v6 · Arquitectura & Concepto

## 🎯 Identidad Principal
**Club social privado de comunidad** — no es una app de citas.

Filosofía: `Descubre → Conecta → Conversa → Planifica → Vive`

---

## 🗺️ Navegación Principal
```
⌂ Inicio
✦ Descubrir
♡ Conexiones
⌖ Mapa
🎁 Drops
◈ Perfil
```

**Chat desaparece de navegación.** Vive dentro de Conexiones.

---

## 🔎 DESCUBRIR

### Pantalla Principal
Conocer personas de la comunidad (no Tinder-style).

**Por persona visible:**
```
VERA · 24
92% conexión

☕ Cafés · ✈ Viajes · ♫ Indie

"Estoy buscando sitios nuevos para cenar 
y gente con quien compartir planes."
```

### Tres acciones:
- **♡ Me interesa** → La añades a "Personas que te interesan" (recomendaciones privadas, sin notificación)
- **👋 Conectar** → Envías una señal (la otra persona recibe notificación)
- **✕ Pasar** → Siguiente perfil

---

## 💕 CONEXIONES (era "Matches")

### Estados de una conexión:

1. **NUEVAS** (conexiones pendientes)
   ```
   Vera quiere conectar contigo ✦
   
   Conectar · Ahora no
   ```

2. **ACTIVAS** (conexión mutua)
   ```
   Vera · 92% conexión
   
   Hablar
   ```

3. **EN CONVERSACIÓN** (han intercambiado mensajes)
   ```
   Lucía · 88% conexión
   Último: "¡Sí, vamos el sábado!"
   
   Hablar
   ```

4. **PLANES** (tienen un plan propuesto)
   ```
   Marta · Café + Paseo
   📍 Centro · Sábado 18:00
   
   Ver plan · Hablar
   ```

```
92% conexión
```

```
ROMPE EL HIELO
```

**Opción 2: Sugerencias de ARX**
```

☕ Proponer plan
```

### Composición de mensajes
```
[Mostrar intereses comunes]

[Botón especial: ☕ Proponer plan]
```

## ☕ PROPONER PLAN (dentro del chat)

### Flujo:

1. **Seleccionar tipo de plan**
   ```
   ¿Qué hacemos?
   
   ☕ Café
   🍸 Tomar algo
   🎬 Cine
   🎮 Gaming
   🚶 Paseo
   🎉 Evento ARX
   ```

2. **ARX genera propuesta**
   ```
   Plan propuesto
   
   Café + paseo
   
   📍 Zona Centro
   🕐 Sábado · 18:00
   
   Enviar propuesta
   ```

3. **La otra persona recibe**
   ```
   Vera te propone
   
   Café + paseo
   📍 Centro · Sábado 18:00
   
   Aceptar · Cambiar · Rechazar
   ```

4. **Si se acepta**
   - Plan aparece en Conexiones
   - Se puede ver en Mapa
   - Opción de convertir en Evento ARX

## ⭐ SUPERCONEXIÓN (ex-Flechazo)

### Concepto
Señal especial para llamar atención cuando **realmente** quieres conectar.

No es el mecanismo principal.

### Mecánica:
```
Superconexiones disponibles: 2

✦ VERA

92% conexión

👋 Conectar

✦ ENVIAR SUPERCONEXIÓN (75 ✦)
```

### Cuando se recibe:
```
✦ ALEX TE HA ENVIADO UNA SUPERCONEXIÓN

Te interesa especialmente.

Conectar · Ahora no
```

### Uso estratégico:
- Pocas disponibles (2-3 por semana)
- Costo en tokens (25-100 ✦)
- Indica interés genuino
- No es "pagar para ganar", es diferenciación

## 🎉 EVENTOS (potenciados)

### Conexiones pueden nacer de eventos

**En evento ARX visible:**
```
NOCHE DE JUEGOS ARX

Hoy · 21:00 · 12 personas

Vera · ☕ ✈ ♫
Lucía · 🎮 🎬
Marta · 🌙 📚

Quiero conocerla
```

### Flujo:
1. Ves personas que van al evento
2. Puedes enviar conexión
3. La conexión nace en contexto (evento, actividad)
4. Mucho más social que perfiles aislados

## 🔑 Cambios clave vs v5

| v5 | v6 |
|---|---|
| Flechazo → Match → Chat | Conectar → Conexión → Chat |
| Chat como sección principal | Chat dentro de Conexiones |
| Matches (palabra neutra) | Conexiones (identidad ARX) |
| Flores: no existen | Flores: regalos 3D coleccionables |
| Sin economía interna | Tokens (moneda de comunidad) |
| Flechazos limitados (5) | Superconexiones (2-3/semana, costo) |
| Eventos desconectados | Eventos generan conexiones |
| Chat sin contexto | Chat con intereses + propuestas |
